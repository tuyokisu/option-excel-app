# オプションExcel作成

オプション一覧から、数式入りの Excel（.xlsx）を作るローカル用の小さなWebアプリです。サーバーやインストールは不要です。

## 使い方

1. このフォルダ一式をPCに置く
2. `開く.bat` をダブルクリックする
3. 仕様名・本体価格・品名・値段を入力する（オプションNoは最初から 1, 2, 3… が入っており、変更できる）
4. **saveする** でアプリ内の `saveデータ` フォルダに保存できる
5. **Excelを作成** でアプリ内の `仕様書一覧` フォルダに Excel が保存される

### 途中保存（saveデータ フォルダ）

- **saveする** … 仕様名の JSON を `saveデータ` に書き込む
- **保存済みを選ぶ → 選んで読み込む** … 続きからオプションを追加できる

`saveデータ` 内の `.json` と `仕様書一覧` 内の `.xlsx` は Git には含めません（個人の作業データ用）。

### 作られるExcel

- **マスタ** … オプションNo・品名・値段
- **入力** … 黄色いセル（B3）に `1,2,3` のようにカンマ区切りで番号を入れると、品目リスト・各行の品名/値段・オプション合計・総合計（本体価格込み）が出ます

Excel 2016 以降、マクロなし。

## ZIPで入手

GitHub の **Releases** に ZIP を置いています。  
リポジトリの **Code → Download ZIP** でも同じ内容を取得できます。

## 開発者向け

```bash
npm test
```

Node.js があればテストのみ実行できます。通常利用では Node は不要です。
