# オプションExcel作成

オプション一覧から、数式入りの Excel（.xlsx）を作るローカル用の小さなWebアプリです。サーバーやインストールは不要です。

## 使い方

1. このフォルダ一式をPCに置く
2. `index.html` を Edge または Chrome で開く（bat は不要）
3. 初回だけ **このアプリのフォルダを指定** で、`index.html` があるフォルダを選ぶ
4. 仕様名・本体価格・品名・値段を入力する（オプションNoは最初から 1, 2, 3… が入っており、変更できる）
5. **saveする** で `saveデータ(読み込むよう）` に保存、**Excelを作成** で `書き込むエクセル` に保存

### 途中保存（saveデータ(読み込むよう） フォルダ）

- **saveする** … `saveデータ(読み込むよう）` のフォルダ一覧から保存先を選び、その中に JSON を書き込む
- **上書き保存** … 読み込んだ JSON、または直前に save したファイルを上書きする
- **保存済みを選ぶ → 選んで読み込む** … 続きからオプションを追加できる

`saveデータ(読み込むよう）` 内の `.json` と Excel フォルダの `.xlsx` は Git には含めません（個人の作業データ用）。

### 作られるExcel

- **マスタ** … オプションNo・品名・値段
- **入力** … 黄色いセル（B3）に `1,2,3` のようにカンマ区切りで番号を入れると、品目リスト・各行の品名/値段・オプション合計・総合計（本体価格込み）が出ます

Excel 2016 以降、マクロなし。

## ZIPで入手

GitHub の **Releases** に ZIP を置いています。  
リポジトリの **Code → Download ZIP** でも同じ内容を取得できます。

## 開発者向け

```bash
npm test
```

Node.js があればテストのみ実行できます。通常利用では Node は不要です。
