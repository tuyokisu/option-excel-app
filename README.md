# オプションExcel作成

オプション一覧の計算結果を、選んだ既存の Excel へ書き込むローカル用の小さなWebアプリです。サーバーやインストールは不要です。

## 使い方

1. このフォルダ一式をPCに置く
2. `index.html` を Edge または Chrome で開く（bat は不要）
3. **JSONのフォルダを選ぶ** と **読み込むフォルダを選ぶ** で、それぞれ好きなフォルダを指定する
4. 仕様名・本体価格・品名・値段を入力する（オプションNoは最初から 1, 2, 3… が入っており、変更できる）
5. **saveする** で選んだJSONフォルダへ保存する。計算結果は **PCのExcelを選ぶ** で指定したファイルの行へ書き込む

### 途中保存

- **JSONのフォルダを選ぶ** … JSONの読み書き先。PC上のどのフォルダでも指定できる
- **saveする** … 選んだフォルダ自身か、その中のフォルダを選んで JSON を書き込む
- **上書き保存** … 読み込んだ JSON、または直前に save したファイルを上書きする
- **保存済みを選ぶ → 選んで読み込む** … 続きからオプションを追加できる

選んだフォルダの中の作業用 `.json` と `.xlsx` は、アプリのフォルダ外にあれば Git には入りません。

### 既存Excelへの書き込み

**PCのExcelを選ぶ** は、読み込み用に選んだフォルダに限らず、PC上のどの `.xlsx` / `.xls` でも指定できます。指定した行へ機種・図番・向け先・作番・本体価格・オプション番号・オプション価格を書き込みます。

Excel 2016 以降、マクロなし。


Node.js があればテストのみ実行できます。通常利用では Node は不要です。
