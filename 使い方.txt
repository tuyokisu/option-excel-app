オプションExcel作成 使い方説明書

■ はじめに
このアプリは、オプション一覧の計算結果を、選んだ既存のExcelへ書き込むためのものです。
インターネット接続は不要です。.bat は使いません。


■ 起動
1. ZIP の場合は右クリック → すべて展開
2. フォルダの中の index.html を Edge または Chrome で開く
3. 同梱の見本を使う場合は、次のフォルダとファイルを選ぶ
   ・JSON … saveデータ(読み込むよう）
   ・読み込むExcel … 読み込み用excel
   ・書き込み先 … 書き込むエクセル\書き込み用.xlsx
   ・該当するオプション … 該当オプション.xlsx
   別のフォルダやファイルでも指定できます

Internet Explorer では動きません。
会社PCで .bat の警告が出ても、実行しないでください。


■ 仕様の入力
・図番番号 … 保存ファイル名とExcel名に使います
・本体価格 … 総合計に含まれます
・入力行数 … Excelで番号から展開する品目の最大件数（100 / 200 / 300 / 500）
・機種 / 図番 / 向け先 / 作番 … 任意。空でも保存・Excel書き込みできます

オプション一覧
・No は最初から 1, 2, 3… が入っています。変更できます
・品名と値段を入力します。空行はExcelに入りません
・11行以上になると一覧はスクロールします
・「行を追加」で次の番号の空行が付きます


■ 保存と読み込み
・JSONのフォルダを選ぶ … JSONの読み書き先です。PC上のどのフォルダでも指定できます
・saveする … 選んだJSONフォルダ自身か、その中のフォルダをクリックして保存します
・上書き保存 … 読み込んだJSON、または直前に save したファイルを、同じ名前のまま上書きします（確認が出ます）
・保存済みを選ぶ … まず選んだフォルダの中のフォルダを選び、その中の JSON をクリックします
  フォルダ名、開いたあとはファイル名で検索できます。件数が多いときは一覧がスクロールします
・選んで読み込む … 選んだ仕様のオプション一覧を画面に戻します
・JSONを消す … 選んだ JSON を削除します（確認が出ます）
・読み込むフォルダを選ぶ → Excelを選ぶ → Excelを読み込む … 選んだフォルダの .xlsx を読み込みます
  （A列ナンバー、B列品目、C列売価。1行目が見出しなら自動で飛ばします）

図番番号を変えて saveする と、別のファイル名で保存します。今開いているファイルを更新するときは上書き保存を使います。


■ 該当するオプション
先にオプション一覧へオプション表を読み込みます。
そのあと計算する番号は、次の2択です。
1. 「選ぶオプションNo」に 1,2,3 と手入力する
2. 丸付きの仕様Excelを読み、○ が付いた左列の番号だけを入れる
丸付きExcelは番号だけ使い、オプション一覧の品名・値段は上書きしません。
番号は各まとまりの左の列だけを見ます。品名の欄に数字が入っていても、その数字は番号にしません。
・PCのExcelを選ぶ … 仕様Excelを選び、丸付き番号を読み込みます
・丸がついた番号を読み込む … 同じファイルをもう一度読みます

■ 仕様書の計算（画面）
読み込んだ（または今編集中の）オプション一覧で計算します。
1. 選ぶオプションNo に 1,2,3 のようにカンマで手入力するか、丸付きExcelから入れる
2. 品目・オプション合計・総合計（本体＋オプション）が出ます
3. 選んだNoと「No 品名」も表示されます
4. 「コピー」で数値や番号をコピーできます（ボタンの右に「コピーしました」）

該当しない番号は「該当なし」と出ます。
別のExcelへ書き込む … 「PCのExcelを選ぶ」で、PC上のどのフォルダの Excel でも選べます。
  枠線・関数・ほかのセルはそのまま残し、指定行の E・G・H だけ更新します。
  .xlsx と同じように、Excel 97-2003（.xls）にもそのまま書き込めます。
  （.xls のまま保存され、開いたときに合計などの関数も計算し直されます）
  パスワード付きの .xls と、Excel 95 以前の .xls には書き込めません。
  （集計用など、書き込みたいブックを直接指定します）
  A列＝機種、B列＝図番、C列＝向け先、D列＝作番（空なら書きません）
  E列＝本体価格、G列＝オプション番号、H列＝オプション価格 を入れます。
  仕様が10件なら、行を 2,3,4… と変えて書き込みます。
  書き込み中は、そのExcelを閉じておいてください。


■ 保存場所
JSONと読み込むExcelは、それぞれ選んだフォルダです。決まった名前のフォルダに限定されません。
計算結果の書き込みは「PCのExcelを選ぶ」で指定したファイルです。PC上のどのフォルダのExcelでも指定できます。


■ うまくいかないとき
・Edge または Chrome で開き直す
・index.html があるフォルダを指定し直す
・フォルダ一式（index.html, app.js, excel-builder.js）が同じ場所にあるか確認する
