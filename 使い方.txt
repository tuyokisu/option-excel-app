オプションExcel作成 使い方説明書

■ はじめに
このアプリは、オプション一覧から数式入りExcelを作るためのものです。
インターネット接続は不要です。.bat は使いません。


■ 起動
1. ZIP の場合は右クリック → すべて展開
2. フォルダの中の index.html を Edge または Chrome で開く
3. 初回だけ「このアプリのフォルダを指定」で、index.html があるフォルダを選ぶ
   （saveデータ と 仕様書一覧 に書き込むため）

Internet Explorer では動きません。
会社PCで .bat の警告が出ても、実行しないでください。


■ 仕様の入力
・仕様名 … 保存ファイル名とExcel名に使います
・本体価格 … 総合計に含まれます
・入力行数 … Excelで番号から展開する品目の最大件数（100 / 200 / 300 / 500）

オプション一覧
・No は最初から 1, 2, 3… が入っています。変更できます
・品名と値段を入力します。空行はExcelに入りません
・11行以上になると一覧はスクロールします
・「行を追加」で次の番号の空行が付きます


■ 保存と読み込み
・saveする … saveデータ フォルダに JSON を保存します
・保存済みを選ぶ … プルダウンを開き、キーワードでファイル名を検索できます
  件数が多いときは一覧がスクロールします
・選んで読み込む … 選んだ仕様のオプション一覧を画面に戻します
・Excelを選ぶ → Excelを読み込む … 仕様書一覧の .xlsx を一覧に入力します
  （A列ナンバー、B列品目、C列売価。1行目が見出しなら自動で飛ばします）

同じ仕様名で保存すると、同じファイル名を上書きします。


■ 仕様書の計算（画面）
読み込んだ（または今編集中の）オプション一覧で計算します。
1. 選ぶオプションNo に 1,2,3 のようにカンマで入力
2. 品目・オプション合計・総合計（本体＋オプション）が出ます
3. 選んだNoと「No 品名」も表示されます
4. 「コピー」で数値や番号をコピーできます（ボタンの右に「コピーしました」）

該当しない番号は「該当なし」と出ます。


■ Excel
「Excelを作成」で 仕様書一覧 フォルダに .xlsx を保存します。
Excelの黄色いセル（B3）に 1,2,3 と入れると、品目リストと合計が出ます。
Excel 2016 以降。マクロは使いません。


■ 保存場所
アプリフォルダの中です。
・saveデータ … 途中保存の JSON
・仕様書一覧 … 作成した Excel

Downloads には保存しません。
フォルダ指定を忘れると保存できません。


■ うまくいかないとき
・Edge または Chrome で開き直す
・index.html があるフォルダを指定し直す
・フォルダ一式（index.html, app.js, excel-builder.js）が同じ場所にあるか確認する
